# JARVIS Memory

Obsidian is the cognitive source of truth. GitHub stores the versioned implementation and schemas. Notion is the operational command center.

## Architecture

- Obsidian: cognitive memory and neural graph
- GitHub: source-controlled implementation
- Notion: operational visibility
- JARVIS: orchestration
- Verification: evidence-based state confirmation

## Memory layers

1. Short-term
2. Episodic
3. Semantic
4. Procedural
5. Long-term

## Lifecycle

INPUT -> CONTEXT -> MEMORY -> PLAN -> ACTION -> EVENT -> VERIFICATION -> MEMORY UPDATE

## Status vocabulary

PLANNED | QUEUED | RUNNING | COMPLETED | FAILED | VERIFIED

## Core rule

An agent claiming success is not equivalent to a verified successful system state. Verification requires evidence.
